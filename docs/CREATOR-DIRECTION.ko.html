사용자 요구에 따른 방향 수정 · 새 제작 기능은 아직 구현 전

Create motion.
Export Lottie.

기존 파일의 색상을 바꾸는 작업실에서, 빈 캔버스로 애니메이션을 만들 수 있는 오픈소스 제작 도구로 제품의 중심을 바로잡습니다.

앞서 전달한 ZIP·데모·테스트는 palette workbench에 대한 결과입니다. 키프레임 제작기까지 완성한 결과가 아닙니다. 기존 기능은 보존하되 새 제작 흐름을 별도로 구현·검증해야 합니다.

사용자가 끝낼 수 있어야 하는 일

새 프로젝트도형·레이어키프레임재생·수정Lottie 다운로드

완성된 Lottie를 가져오지 않아도 만들 수 있어야 합니다. 템플릿과 팔레트는 보조 시작점이지 제작 기능의 대체물이 아닙니다.

첫 제작 버전

  • 빈 캔버스와 크기·fps·길이 설정.
  • 사각형·원 추가, 선택·이동·크기·색상·복제·삭제·레이어 순서.
  • 실제 레이어 타임라인과 position·scale·rotation·opacity 키프레임.
  • 재생·seek·easing, undo/redo.
  • 재편집 가능한 Moro 프로젝트 저장/열기와 실제 Lottie JSON export.

화면 결정

상단   New / 프로젝트 이름 / undo·redo / Export
왼쪽   Layers · Shapes · Templates
중앙   직접 선택·드래그·resize하는 캔버스
오른쪽 도형·스타일·transform / keyframe 추가
하단   레이어 트랙 · time ruler · playhead · keyframes

기존 밝은 framed-sheet와 글꼴은 유지합니다. 기존 파일의 recolor 작업은 별도 보조 모드로 살립니다. 재생 막대의 이름만 타임라인으로 바꾸지 않습니다.

구현의 첫 통과 기준

빈 프로젝트 → 원 추가 → 0초/1초의 X 위치 작성 → 이동 재생 → Lottie JSON 다운로드 → 독립 player에서 같은 이동 확인.

이 수직 흐름을 먼저 통과하고, 레이어·속성·프로젝트 저장을 확장합니다. 자체 편집 문서와 Lottie exporter를 분리해 UI 밖에서도 제작 코어를 재사용할 수 있게 설계합니다. 실제 npm 패키지 공개는 별도 승인 단계입니다.

약속하지 않을 것

첫 버전부터 임의 Lottie 전체를 완전한 editable scene으로 역변환하거나, After Effects 수준의 모든 표현을 지원한다고 주장하지 않습니다. text/font·SVG import·펜 도구·AI 생성은 이후 범위입니다. 로그인·클라우드·모델 API key는 기본 제작 흐름에 넣지 않습니다.

진짜 데모의 기준도 변경

색상만 바뀌는 샘플 대신, 사용자가 빈 화면에서 도형을 만들고 움직임을 작성하며 내보낸 파일을 다시 재생하는 장면을 담아야 합니다. 문서·테스트 수·아름다운 샘플만으로 새 제작 도구가 완성됐다고 보고하지 않습니다.
