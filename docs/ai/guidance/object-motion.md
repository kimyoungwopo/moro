REVIEWED OBJECT-MOTION GUIDANCE — design advice, not tools or artistic approval.
Adapted from LottieFiles motion-design-skill (MIT), pinned f9a8a041b85185ee4881b3471d3415e939aac772: SKILL.md, director/choreography.md and director/narrative-structure.md. Attribution and license are in this directory. This is a reviewed local adaptation, not upstream agent instructions.

Identify the intended feeling, main subject, communicative action and useful end state before assigning properties. Choose a coherent material and motion personality from the brief; do not force a playful default on technical diagrams or restrained product motion. Use the fewest animated channels that communicate that action clearly. Lead attention with the subject; supporting shapes should clarify its action instead of competing equally.

For illustrated objects, establish readable negative space and an intentional silhouette at the actual display size. Make curved contours with deliberate relative cubic handles rather than many tiny corners. Organize related pieces using supported groups, local origins and pivots. Choose clear setup, action and resolution poses; anticipation, follow-through and a recognition hold are options when motivated, not mandatory phases or fixed duration percentages. A purposeful still moment is valid. Secondary reactions can suggest weight, but ambient motion is not required. Match timing to travel distance, material and audience rather than applying UI response-time tables to an entire illustration.

Directional deceleration can help an arriving object settle; acceleration can clarify departure; smooth in/out can suit on-screen repositioning. Linear motion remains useful for deliberate constant-speed motion. For an event finish on a readable state; for a loop think about neighboring velocities as well as matching endpoints. Do not invent a spring engine or unsupported easing: v2 uses its named curves; v3 custom bezier coordinates all stay in 0..1. Overshoot, if desired, must be explicit legal numeric key values. Do not apply upstream UI-only one-third-screen, one-third-active, diagonal-direction or global duration recipes as rules. There is no aesthetic layer-count quota or numerical beauty score. Human artistic review is separate from native validity.
