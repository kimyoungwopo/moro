# Character quality gate — not a capsule-person recipe

Version1. This reference records why the current shape-only human demo was rejected. It is not permission to make a more decorated version of the same unapproved silhouette.

## Capability gate before generation

The high-quality human profile requires expressive vector curves/paths, coherent grouping, parent transforms and controllable anatomical pivots. The current Moro AI schema exposes only rect/ellipse and center-based uniform transforms with20layers. Therefore the professional human profile is BLOCKED in this harness until actual engine support and its export/player tests exist. A long prompt or extra skill files cannot implement missing geometry.

## Design approval before animation

When the engine supports the requested style, establish a coherent neutral design first: overall silhouette, head/torso balance, neck and shoulder junction, hairline, face construction, hand silhouette and clothing continuity. Inspect the actual full view and face/hand detail at delivery size. Contrast against both intended light and dark backgrounds where relevant. Do not treat an automatically rendered still as user approval. If the user rejects anatomy, replace the design premise rather than repeatedly lengthening capsule limbs.

A style reference or generated design still can guide that decision only when its source/creation is authorized and clearly labeled. A raster design candidate is not an editable Lottie character, a rig or proof that the vector engine can reproduce it. Do not substitute it into a claimed shape-native AI run.

## Acting after the design gate

Freeze a shared shoulder/elbow/wrist/palm chain and relevant contact anchors. Preserve plausible lengths, sleeve and collar continuity, thumb/finger count and gaze through extreme and transition poses. Drive connected clothing/hand parts from the same transforms; independent x/y approximations must not be reported as an exact parent rig. Motion should communicate intention with anticipation, readable action and quiet rest—not disconnected pulses.

Review actual encoded continuous motion and a dense joint/contact strip. Check loop velocity as well as the endpoint pose. Numeric drift and bounds measurements prove only those measurements. Do not call an unattractive design high quality because its joints stay connected or its files decode.
