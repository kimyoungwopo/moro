실제 쇼핑 앱의 주문 완료 화면에 넣을 수 있는, 구성 요소가 서로 맞물리는 5초짜리 프리미엄 Lottie 이벤트 모션을 새로 디자인해줘. 주제는 '주문이 안전하게 포장되어 배송 준비가 끝남'이야. 꽃/단일 아이콘 반복이 아니라, 여러 사물과 상태가 시간차로 이어지는 작은 제품 온보딩 장면이어야 해.

512×512 투명 캔버스, 60fps, 300프레임. 루프가 아닌 단발 이벤트: 자동으로 처음 상태로 돌아가거나 전체 장면이 사라지면 안 되고 마지막에는 '준비 완료'를 명확하게 유지해줘. 가상 쇼핑 앱의 일러스트이며 실제 거래/브랜드를 묘사하지 않아. 글자·숫자·브랜드 로고·사람·얼굴·배경 사각형은 넣지 마.

장면의 흐름:
- 0.0–0.6초: 중앙의 열린 배송 상자가 약간의 회전과 압축/복원으로 자리를 잡음. 바닥 그림자는 조용하게 접지를 설명함.
- 0.5–1.8초: 서로 구분되는 상품 카드/작은 포장물 3개가 부채꼴의 다른 경로와 다른 시차로 상자 안에 들어감. 한 덩어리처럼 동시에 떨어지거나 서로 분리된 장식이 떠다니는 느낌은 피함.
- 1.7–2.8초: 좌우 덮개가 실제 접힌 모서리를 회전축으로 삼아 차례로 닫힘. 안쪽·상품·덮개·앞면의 앞뒤 paint order를 설계해서 상품이 상자 밖으로 비치거나, 덮개가 엉뚱한 중심에서 회전하지 않아야 함. 화면의 3/4 방향 평면 일러스트로 깊이를 주되 지원하지 않는 진짜 3D 기능은 쓰지 않음.
- 2.7–3.6초: 박스가 짧게 반응하며 위/옆에 충분히 큰 완료 원형 배지와 연결된 체크가 anticipation → overshoot → settle로 나타남. 작은 색종이 6개 정도만 비대칭 방향/중력/회전으로 터졌다가 사라짐. 별뿌리기·무작위 점들로 복잡도를 대신하지 말 것.
- 3.6–5.0초: 완료된 상자와 배지를 안정적으로 홀드. 접지와 체크가 분명하고 마지막 프레임까지 의미 있는 완료 상태가 남음.

색은 잉크 네이비/선명한 블루/따뜻한 크림·노랑의 제한된 팔레트, 일관된 모서리/선 굵기, 정돈된 오버랩과 충분한 여백으로 디자인해줘. 화면의 중심 피사체가 너무 작으면 안 돼. 실제 160px 표시에서도 상자·완료 배지가 읽혀야 함. 중요한 바깥 윤곽은 모든 프레임에서 캔버스 안에 있어야 해.

현재 Moro v2의 rect/ellipse/정적 cubic path, parentId/group, 정적 pivot, 숫자 위치·회전·scale·opacity 트랙만 사용해. 그룹은 transform-only이며 opacity는 100, opacity 트랙은 빈 배열이야. 곡선과 연결된 모양, 실제 부모 그룹/힌지 pivot을 활용하고 지지물은 안정적으로 유지해. path morph·마스크·외부 이미지·폰트·코드/표현식은 지원하지 않으니 사용하지 마. 가림은 도형 paint order와 필요한 시점의 개별 도형 opacity로 해결해. 총 노드는 대략 24–32개 이내, 트랙은 읽히는 동작에 꼭 필요한 키만. 모든 키의 frame은 0..299이며 끝의 홀드도 설계해줘. 기존 프로젝트는 제공하지 않으니 모양·구도·부모 관계·타이밍을 네가 새로 설계한 완전한 편집용 v2 프로젝트로 반환해줘.
