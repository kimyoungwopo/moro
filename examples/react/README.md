# Generated React example

The three components are generated by the same `reactSource` function used by the workbench Export modal. They demonstrate autoplay, hover/focus and click/tap with a visible keyboard-accessible play/pause button.

```sh
npm ci
npm run build
npm run dev
```

From the repository root, `npm run example:generate` regenerates the component files, declaration and matching JSON. `npm run example:dev` serves them on 127.0.0.1:4176.

Install versions are pinned in package.json and package-lock.json. `lottie-light.d.ts` declares the expression-free light-player import. `resolveJsonModule` is enabled in tsconfig.json. The player receives a clone and is destroyed on unmount. Reduced-motion environments start paused; the play button remains explicit control.
