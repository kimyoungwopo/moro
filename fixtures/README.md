# Fixture provenance

All fixtures and three public samples are original geometric animations created for this project, MIT licensed. No assets or source bundles were copied from the LottieFiles reverse-engineering report.

- `apps/web/public/samples/{orbit,success,burst}.json`: generated by `scripts/generate-samples.mjs`.
- `supported-complex.json`: nested precomposition with static RGB/alpha, a gradient, animated color and unknown metadata.
- `blocked-external.json`: original sample with deliberately invalid external image/font URLs.
- `blocked-expression.json`: original sample with an inert expression string; it must never reach a player.
- `malformed.json`: deliberately broken syntax.

Budgets are conservative implementation caps, exercised by synthetic deep/wide/oversized fixtures in `tests/document.test.ts`; this is not a physical low-end-device performance certification.
